# Minecraft_Rusted_JE
>该开源项目仅供参考，请支持正版，
-
此MOD主要是为了90%还原原版Minecraft，目前还处于测试阶段\n
这水和岩浆比较吃CPU和GPU，如果你设备性能比较低的话那最好下载c0.0.11a及以前的版本\n
目前MOD的最低配置要求\n
CPU: 高通685/MTK 天玑1200/Intel Core i3-530 x86_64/Intel Xeon E5-2666v3/Intel Xeon E3-1220v2/Intel 奔腾 G2120/AMD R3-2200G
GPU: Mali-G60/Adreno600/HD3000/GT1030/AMD R7-240/GTX750
显存: 1.5GB以上
RAM: 4GB DDR3 1333Mhz
